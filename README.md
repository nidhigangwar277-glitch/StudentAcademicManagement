# Student Academic Management System

## Overview

The Student Academic Management System is a simple Java-based console application developed to manage basic academic information of students.

The system allows users to add, view, search, update and delete student academic records.

## Features

- Add a new student
- View all students
- Search student by ID
- Update student marks
- Delete student record
- Simple menu-driven interface

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner
