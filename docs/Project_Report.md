# Project Report

## Student Academic Management System

### 1. Introduction

The Student Academic Management System is a console-based Java application developed to manage basic student academic records.

### 2. Objectives

The main objectives of this project are:

1. To maintain student records.
2. To provide an option to add students.
3. To display all student records.
4. To search for students using their ID.
5. To update student marks.
6. To delete student records.

### 3. Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner

### 4. Functionalities

#### Add Student
Allows the user to enter the student's ID, name, course and marks.

#### View Students
Displays all students currently stored in the system.

#### Search Student
Searches for a student using their unique ID.

#### Update Marks
Allows the user to modify the marks of an existing student.

#### Delete Student
Removes a student record using the student's ID.

### 5. Concepts Used

The project demonstrates:

- Classes and Objects
- Constructors
- Methods
- ArrayList
- Loops
- Conditional Statements
- Switch Case
- User Input using Scanner

### 6. Conclusion

The project provides a simple implementation of an academic management system using Java. It demonstrates fundamental programming and Object-Oriented Programming concepts in a practical application.
